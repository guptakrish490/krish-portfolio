# Krish Gupta — Portfolio

A Next.js portfolio focused on backend engineering, projects, and the systems behind software.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Deploy

Import this repository into Vercel with the project root set to the repository root. The default Next.js build settings are sufficient; no environment variables are currently required. The resume is served from `public/Krish_Gupta_Resume.pdf`.

## Project layout

- `app/` — App Router page, layout, styles, project content, and components.
- `public/` — portrait assets and the downloadable resume.
- `details.md` and `portfolio_build_prompt.md` — project source notes and design brief.
